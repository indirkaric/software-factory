name: software-factory-run
description: Shortcut for /software-factory run. Use when the user types /software-factory-run or /software-factory-run <issue number>.

Invoke the `software-factory` skill with the arguments `run $ARGUMENTS` and
follow it. `/software-factory-run 1` is `/software-factory run 1`: issue #1.
